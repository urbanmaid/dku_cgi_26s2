# POC 설계 명세서

# 소개

- **장르:** 3D 액션 플랫포머
- **배경:** 근미래 도시 및 인공 구조물
- **핵심 경험:** 빠르고 연속적인 이동을 통한 공간 돌파
- **주요 조작:** 이동, 점프, 벽타기 및 벽점프, 연속 동작
- **플레이 방향:** 전투보다는 이동과 공간 탐색에 집중
- **플레이 감각:** 속도감, 리듬감, 관성, 연속성

**이동 자체가 플레이의 목적이 되는 근미래 배경의 3D 플랫포머 게임.**

점프와 벽타기, 연속적인 이동 액션을 조합하여 플레이어가 공간을 빠르고 유려하게 돌파하는 과정에서 재미를 느끼도록 한다.

단순히 달리고 점프하는 것에 그치지 않고, 점프 → 벽타기 → 도약 → 착지와 같은 행동을 자연스럽게 이어나갈 수 있도록 한다.

# 구현 사항

## 플레이어에게 주어진 목표

플레이어는 목표 지점으로 이동하면서 중간 기착지점에서 편지를 전부 수집하는 작업을 수행해야 한다.

## 레벨 디자인 중점 요소

기본 스테이지 및 수행 사항(해당 사항은 선형적으로 구현되어야 함)

- **이동**
- **점프**
    - 기본 점프 - 점프로만 통과할 수 있는 장애물
    - 점프의 연속 - 벽타기로만 통과할 수 있는 장애물
- **슬라이드**
    - 기본 슬라이드 - 슬라이드로만 통과할 수 있는 장애물
    - 슬라이드 > 점프 - 슬라이드 후 바로 점프로 동작을 이어나가야 함
    - 점프 > 슬라이드 - 점프 유지 시 데미지를 입을 수 있는 장애물을 배치
- **수집 요소 (4-5개 배치)**
    - 수집 요소의 첫 번째 배치
    - 연속된 수집 요소의 배치와 해당 배치 요소의 도달 조건을 선행 동작으로 습득
- **도착 지점**

추가 구현 사항(선형적 구현 사항 사이에 포함됨)

- **수집 요소**
    - 상호작용으로만 작동시킬 수 있는 도로 - 상호작용을 의무적으로 함으로써 도로를 개방하는 동작이 포함됨

# 조작

- **점프**
    - 벽과 맞닿아 있을 경우 벽 반대 방향으로 벽차기 점프
- **슬라이드**
    - 공중에 있을 경우 이동 방향으로 빠르게 착지
    - 지상에 있을 경우 이동 방향으로 슬라이드
- **시점 재조정**
    - 이동 방향으로 재조정하기
- **상호작용**
    - NPC와의 대화의 경우 대화 시작 및 넘기기
    - 스테이지 진입 포탈에 있을 경우 스테이지 진입

**Xbox 컨트롤러**

- LS - 이동
- A - 점프
- B - 슬라이드
- RS - 시점 조정
- Y - 시점 재조정
- X - 상호작용

 **키보드, 마우스**

- WASD - 이동
- Ctrl - 천천히 이동
- Space - 점프
- Shift - 슬라이드
- 마우스 이동 - 시점 조정
- 마우스 휠 버튼 - 시점 재조정
- E - 상호작용

# 구현 수준

## 그래픽

- POC이므로 플레이어와 중간 목표, 최종 목표, 장애물 등을 구분할 수 있는 수준만 구현할 것
- 상호작용을 통해 플레이 팁을 알려주는 개체는 Debug Log를 사용(나중에 UI랑 연결할 거임)

## 레벨

- 튜토리얼 스테이지 수준의 조작 습득 과정을 주로 묘사할 것
- 선형 진행을 전제로 구현
