# City Courier POC 실행 안내

`Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다. 모든 과정은 이 씬 안에서 진행되며 Canvas, HUD, 대화 UI는 없습니다. 안내, 수집 현황, 피격, 클리어 메시지는 Unity Console에서 확인합니다.

## 시작과 목표

1. 시작 위치 왼쪽의 청록색 안내원 가까이에서 E / Xbox X로 안내를 듣습니다. 반복 입력하면 다음 대사가 출력됩니다.
2. 파란 출발 포탈 가까이에서 E / X를 누릅니다. 같은 씬의 코스 시작 지점으로 이동합니다.
3. 이동 → 기본 점프 → 청록색 벽타기 → 기본 슬라이드 → 슬라이드 후 점프 → 점프 후 급강하·슬라이드 순서로 진행합니다.
4. 노란 편지 5개를 수집합니다. 각 편지 뒤의 초록색 바닥 표시는 체크포인트입니다.
5. 마지막 구간의 노란 도로 제어기 가까이에서 E / X를 눌러 다리를 연결합니다.
6. 초록색 도착 지점에 접근합니다. 편지 5개 수집과 도로 개방이 모두 완료되면 목적지 색상이 금색으로 바뀌고 배달 완료 로그가 출력됩니다.

## 조작

| 동작 | 키보드 / 마우스 | Xbox |
|---|---|---|
| 이동 | WASD | LS |
| 천천히 이동 | Ctrl 유지 | LS를 조금 기울이기 |
| 점프 / 벽점프 | Space | A |
| 슬라이드 / 공중 급강하 | Shift | B |
| 시점 조절 | 마우스 이동 | RS |
| 이동 방향으로 시점 재조정 | 마우스 휠 버튼 | Y |
| 대화 진행 / 포탈 / 도로 제어기 | E | X |
| 마우스 해제 / 다시 잠그기 | Esc / 왼쪽 클릭 | — |

슬라이드는 누르는 즉시 시작하고 최소 0.65초 동안 지속됩니다. 버튼을 누르고 있거나 천장이 낮으면 낮은 자세를 유지합니다. 공간이 충분하면 슬라이드 중 점프로 연계할 수 있습니다. 공중 슬라이드는 전방으로 급강하한 뒤 착지 슬라이드로 이어집니다.

청록색 벽 가까이에서 점프하고 전진하면 최대 2.5초 동안 벽타기가 적용됩니다. 벽 옆에서 점프를 다시 누르면 벽 반대 방향으로 도약합니다. 긴 틈은 일반 점프 한 번으로 건널 수 없습니다. 벽타기 구간 진입 전에 벽 쪽으로 붙으세요.

빨간 레이저에 닿거나 추락하면 피격 횟수가 증가하고 최근 체크포인트로 복귀합니다. 편지 수집과 도로 개방 상태는 유지됩니다. 클리어 후 다시 하려면 Play를 종료하고 재시작합니다.

## 구성과 수정

- `Assets/Scripts/Parkour`: 입력, 플레이어 이동, 카메라, 진행 상태, 트리거, 상호작용 컴포넌트.
- `Assets/Art/CityCourier`: 구분용 URP 머티리얼.
- `Assets/Tests/PlayMode`: 장애물 통과, 벽타기·벽점프, 연계 동작, 피격 복귀, 수집 및 클리어 조건 자동 테스트.
- `Tools > City Courier > Rebuild SampleScene POC`: 코스 기본 배치를 다시 생성합니다. SampleScene을 열고 저장하며, `City Courier POC` 하위의 수동 수정 내용은 초기화합니다.

코스는 런타임 생성이 아닌 씬에 저장된 오브젝트로 구성됩니다. Hierarchy에서 장애물과 트리거를 직접 수정할 수 있습니다. `CourierMotor`의 속도, 점프, 중력, 벽타기 지속 시간은 Inspector에서 조정할 수 있습니다. `CourierStage.LettersChanged`와 `StageCompleted` 이벤트를 통해 추후 UI를 연결할 수 있습니다.

기존 실습 스크립트는 보존하고 SampleScene의 GL 데모 오브젝트만 교체합니다. 씬 추가나 씬 전환은 없습니다.

## 검증

Unity 6000.4.0f1의 Play Mode 자동 테스트 10개를 통과했습니다. 전체 코스를 순간이동 없이 통과하여 편지 5개를 수집하고, 도로 제어기를 작동시킨 뒤 도착 트리거로 클리어하는 경로도 포함합니다. 개별 테스트는 기본 점프, 낮은 천장에서 자세 유지, 긴 틈 벽타기, 벽점프 방향, 슬라이드→점프, 점프→급강하, 레이저 피격 복귀, 중복 수집 방지 및 도로·완료 조건을 검사합니다.

다시 검증하려면 Unity의 `Window > General > Test Runner`에서 PlayMode의 `CourierPlayModeTests`를 실행합니다. 실제 Xbox 장치의 입력과 사람이 느끼는 난이도는 별도로 플레이하며 조정할 수 있습니다.
